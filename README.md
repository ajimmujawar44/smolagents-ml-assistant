## 📌 Overview

**AI ML Code Agent** is an AI-powered application designed to simplify machine learning development. It allows users to upload CSV datasets, inspect their data, and describe machine learning tasks using natural language.

Powered by **SmolAgents and Google's Gemini models**, the agent generates Python code and suggests practical approaches for solving machine learning problems.

The interactive Gradio interface makes it easier for beginners and data science practitioners to explore datasets and develop ML workflows without writing every line of code manually.

## ✨ Key Features

- 📂 **CSV Dataset Upload:** Upload your own dataset for analysis.
- 🔍 **Automated Dataset Inspection:** View dataset dimensions, column names, data types, duplicate rows, missing values, and sample records.
- 🤖 **AI-Powered Code Generation:** Generate Python code for machine learning and data science tasks using natural-language prompts.
- 🧠 **Machine Learning Guidance:** Get recommendations for classification, regression, preprocessing, and model evaluation.
- 🧹 **Data Preprocessing Suggestions:** Explore strategies for handling missing values and categorical features.
- 📊 **Exploratory Data Analysis:** Request EDA summaries and visualization suggestions.
- 🔎 **Web Search Integration:** Use DuckDuckGo search through the agent's configured tool.
- 🔄 **Error Handling and Retries:** Retry selected temporary API failures.
- 🎨 **Interactive Gradio Dashboard:** Access the application through a browser-based interface.
- 🔐 **Environment-Based API Configuration:** Store your API key in a local `.env` file instead of hardcoding it into the application.

## 🏗️ Workflow

1. Upload a CSV dataset.
2. Inspect the dataset structure and data quality.
3. Describe the machine learning task in natural language.
4. Send the task and dataset summary to the AI agent.
5. Receive generated Python code and a suggested ML workflow.
6. Review the generated solution and execute it separately in an appropriate environment.

**Note:** The current application generates code and recommendations. It does not automatically execute the generated ML solution or guarantee model performance.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-ml-code-agent.git
cd ai-ml-code-agent
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the Gemini API key

Create a `.env` file in the project directory:

```env
GOOGLE_API_KEY=your_google_api_key_here
```

Obtain your API key through [Google AI Studio](https://aistudio.google.com/).

**Security:** Never upload your `.env` file or expose your API key in a public repository.

### 5. Launch the application

Open `ml_code_agent_fixed.ipynb` in Jupyter Notebook or VS Code.

Run the notebook cells **from top to bottom**. The final cell launches the Gradio application in your browser.

Make sure the configured Gemini model ID is supported by your account and the installed LiteLLM integration.

## 🚀 How to Use

1. Open the Gradio dashboard.
2. Upload a CSV dataset.
3. Click **Analyze dataset** to inspect its structure and quality.
4. Enter a machine learning task in the prompt box.
5. Click the generate button.
6. Review the generated code, methodology, assumptions, and evaluation recommendations.
7. Copy the code into your development environment, validate it, and run it separately.

## 🔐 Security and Responsible Use

- Keep API credentials in environment variables.
- Never commit `.env` files or API keys.
- Review AI-generated code before running it.
- Do not provide sensitive or confidential datasets to external AI services without appropriate authorization.
- Generated code may contain errors and must be validated before use.
- Apply appropriate sandboxing and access restrictions before deploying code-execution capabilities.

## ⚠️ Limitations

- A valid Gemini API key and supported model configuration are required.
- API availability, quotas, and rate limits may affect requests.
- The quality of generated code depends on the prompt, dataset summary, and model output.
- The agent does not guarantee that generated code is correct or that a model will achieve a particular score.
- Generated ML code must be reviewed and executed separately.
- The current implementation is a notebook-based local application, not a production deployment.
